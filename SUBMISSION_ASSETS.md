# Submission Asset Manifest

## Required / Recommended artifacts

- README.md — project overview and setup instructions.
- SUBMISSION.md — concise judge-ready summary of the problem, solution, and scope.
- ARCHITECTURE.md — architecture and decision-boundary explanation.
- DEMO_SCRIPT.md — presenter walkthrough and judge questions.
- JUDGE_QA.md — concise oral Q&A for final defense.
- FINAL_DEMO_CHECKLIST.md — execution plan, backup mode, and screenshot workflow.
- screenshots — visual proof of the dashboard, risk values, root cause, and verification states.
- short demo video if required — live walkthrough for remote or asynchronous review.
- source code — implementation of the deterministic engine, dashboard, and evidence layer.
- test result screenshot — evidence that the final verification suite is passing.
- BigQuery screenshot — visual confirmation of the evidence layer when a live environment is available.
- dashboard screenshot — proof of the final AEGIS case view.

These artifacts collectively show the security story, the implementation, the validation path, and the judge-facing narrative without overstating the current production scope.
